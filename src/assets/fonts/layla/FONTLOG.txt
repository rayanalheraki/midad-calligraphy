FONTLOG for the LaylaFontFamily fonts

This file provides detailed information on the LaylaFontFamily Font Software. This information should be distributed along with the LaylaFontFamily fonts and any derivative works.

Basic Font Information

LaylaFontFamily is a Unicode typeface family that supports Arabic language, and could be expanded to support other scripts in the future.

This release contains the following fonts:
- LaylaBasicArabic  : Naskh font
- LaylaBoxer        : Designed font
- LaylaThuluth      : Thuluth font
- LaylaKoufi        : Koufi font
- LaylaRuqaa        : Ruqaa font
- LaylaDiwani       : Diwani font
- LaylaArcyArc      : Designed font
- LaylaDigital      : Designed font

Documentation can be found at [http://sites.google.com/site/mohammedisam2000/layla-fonts]
To contribute to the project, contact the author at [mohammed_isam1984@yahoo.com]
