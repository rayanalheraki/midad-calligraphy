# كِلك ويب — Kelk Web

محرِّر للخط العربي يعمل بالكامل داخل المتصفح، فرونت-إند بالكامل، بواجهة عربية من اليمين إلى اليسار.
أُعيد بناؤه من هندسة عكسية لبرنامج **Kelk 2010** لسطح المكتب (تفاصيلها في
[`تقرير-الهندسة-العكسية.md`](تقرير-الهندسة-العكسية.md)) دون نسخ أي شفرة أو خط منه.

## التشغيل محليًّا

المتطلّبات: Node.js 20+.

```bash
cd kelk-web
npm install
npm run dev
```

ثم افتح `http://127.0.0.1:5173`.

للبناء والتشغيل كنسخة إنتاج (خادم ثابت مع رؤوس أمان صارمة على `127.0.0.1` فقط):

```bash
npm run build
npm start
```

للاختبارات:

```bash
npm test
```

لاختبار قارئ `.klx` ضدّ مستندات كِلك الأصلية أيضًا، مرِّر مسار مجلد العيّنات:

```bash
KELK_SAMPLES=/path/to/Samples npm test
```

## الميزات

- **أسطر خطية** بتشكيل عربي كامل عبر HarfBuzz (WASM)، مع مجموعات أسلوبية (ss01…) وربطات.
- **تحرير كل حرف ونقطة وحركة** بالسحب والدوران والتحجيم والإخفاء وتلوين مستقل — جوهر فكرة كِلك.
- **الكشيدة (التطويل)**: تلقائية بمواضع تقليدية (بعد السين، قبل النون/الميم النهائية)، لا تكسر لام-ألف ولا تطيل لفظ الجلالة؛ وكشيدة يدوية لكل حرف؛ وضبط طول السطر إلى عرض محدَّد.
- **المسارات**: مستقيم، قوس، دائرة، موجة. **التكرار الدوراني** (وردة) و**المُثنّى** (مرآة).
- **زخارف وأشكال**: إطارات بسيطة ومزدوجة ومزخرفة، محراب، شمسة، وردة، نجمة، خاتم، فاصل، نقطة القلم.
- **قلم القصب**: محاكاة السنّ المبريّ (خطّ غليظ عموديًّا على السنّ ورفيع موازيًا له) مع حساسية الضغط.
- **خلفيات ونقوش هندسية** إسلامية، وتدرّجات، وصور خلفية.
- طبقات، محاذاة وتوزيع، التقاط وأدلة، مساطر بالمليمتر، تراجع/إعادة، اختصارات لوحة مفاتيح.
- **حفظ تلقائي** و«أعمالي» داخل المتصفح (IndexedDB)، وملفات مشروع `.kelk.json`.
- **استيراد مستندات كِلك الأصلية `.klx`** (2000–2010) بفكّ تشفير النصوص وتعيين الأنماط لأقرب خط حرّ.
- **تصدير** PNG و JPEG و SVG متجه (الحروف مسارات) و PDF عبر الطباعة.
- **خطوط المستخدم**: إضافة ملفات TTF/OTF محليًّا (تبقى في المتصفح).
- لوحة مفاتيح عربية على الشاشة ولوحة حركات ورموز قرآنية.

## الأمان والخصوصية

- لا اتصال بأي خادم خارجي؛ الخطوط ومحرك التشكيل مضمّنة.
- خادم الإنتاج يرسل CSP صارمة و`X-Content-Type-Options` و`frame-ancestors 'none'`، ويمنع اجتياز المسارات، ويستمع على `127.0.0.1` فقط.
- الملفات المفتوحة تُفحص: مشاريع JSON تُقبل حقولها المعروفة فقط، والصور يُعاد ترميزها (يُرفض SVG)، وقارئ `.klx` محدود الحجم والعمق.
- لا يحتاج إلى صلاحيات مدير ولا تعريفات ولا تعطيل أي إعداد أمان.

## البنية

```
src/
  model/      نموذج المستند، التحقّق والتصفية، النماذج الجاهزة
  engine/     العربية والكشيدة، تشكيل HarfBuzz، التخطيط، الزخارف، النقوش، قلم القصب، الخطوط
  io/         صفحة ترميز Sina، قارئ KLX، الاستيراد، التصدير، المشاريع، التخزين، الصور
  render/     عارض SVG مشترك بين المحرّر والتصدير
  store/      حالة المحرّر (Zustand + Immer) وحالة الخطوط
  ui/         الشريط العلوي، الأدوات، اللوحة، المفتّش، الحوارات، لوحة المفاتيح، اللوحة الجانبية
tests/        اختبارات المحرّك والاستيراد والتحقّق (Vitest)
server.mjs    خادم ثابت لنسخة الإنتاج برؤوس أمان
```
