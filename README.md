# مِداد — محرّر الخط العربي

محرِّر للخط العربي يعمل بالكامل داخل المتصفح، بواجهة عربية من اليمين إلى اليسار.

## التشغيل محليًّا

المتطلّبات: Node.js 20 أو أحدث.

```bash
npm install
npm run dev
```

ثم افتح `http://127.0.0.1:5173`.

للبناء والتشغيل كنسخة إنتاج (خادم ثابت مع رؤوس أمان صارمة على `127.0.0.1` فقط):

```bash
npm run build
npm start
```

للاختبارات:

```bash
npm test
```

لاختبار قارئ ملفات KLX على مجلد عيّنات حقيقية أيضًا:

```bash
KLX_SAMPLES=/path/to/samples npm test
```

## الميزات

- **أسطر خطية** بتشكيل عربي كامل عبر HarfBuzz، مع مجموعات أسلوبية وربطات.
- **تحرير كل حرف ونقطة وحركة** داخل السطر: سحب، دوران، تحجيم، إخفاء، ولون مستقل.
- **التشكيل والعناصر المنفصلة** (الأداة `M`): حركات، نقاط القلم (نقطة، نقطتان، ثلاث نقاط)، علامات التزيين الصغيرة، علامات المصحف، ورموز مثل ﷽ و ﷺ. يوضع كل عنصر بنقرة في الصفحة كعنصر مستقل، ويأخذ خط السطر المحدد وحجمه ولونه ويتحرك معه.
- **حركات داخل النص**: لوحة تُدرج الحركة عند مؤشّر الكتابة فيضعها الخط تلقائيًّا.
- **الكشيدة**: تلقائية في مواضعها التقليدية (لا تكسر لام-ألف ولا تطيل لفظ الجلالة)، ويدوية لكل حرف، وضبط طول السطر.
- **المسارات**: مستقيم، قوس، دائرة، موجة. **التكرار الدوراني** و**المُثنّى**.
- **خلفيات** بألوان وتدرّجات ونقوش هندسية وصور.
- طبقات، محاذاة وتوزيع، أدلة التقاط، مساطر بالمليمتر، تراجع/إعادة، اختصارات.
- **حفظ تلقائي** و«أعمالي» داخل المتصفح، وملفات مشروع `.midad.json`.
- **استيراد ملفات KLX** القديمة مع فكّ ترميز نصوصها.
- **تصدير** PNG و JPEG و SVG متجه و PDF عبر الطباعة.
- **خطوط المستخدم**: إضافة ملفات TTF/OTF محليًّا.
- نماذج جاهزة، ويفتح التطبيق أول مرة على نموذج «الختم الدائري».

## الأمان والخصوصية

- لا اتصال بأي خادم خارجي؛ الخطوط ومحرك التشكيل مضمّنة.
- خادم الإنتاج يرسل CSP صارمة و`X-Content-Type-Options` و`frame-ancestors 'none'`، ويمنع اجتياز المسارات، ويستمع على `127.0.0.1` فقط.
- الملفات المفتوحة تُفحص: المشاريع تُقبل حقولها المعروفة فقط، والصور يُعاد ترميزها (يُرفض SVG)، وقارئ KLX محدود الحجم والعمق.
- لا يحتاج إلى صلاحيات مدير ولا تعريفات.

## البنية

```
src/
  model/      نموذج المستند، كتالوج العناصر، التحقّق، النماذج الجاهزة
  engine/     العربية والكشيدة، تشكيل HarfBuzz، تخطيط الأسطر، هندسة العناصر، النقوش، الخطوط
  io/         قارئ KLX واستيراده، التصدير، المشاريع، التخزين، الصور
  render/     عارض SVG مشترك بين المحرّر والتصدير
  store/      حالة المحرّر (Zustand + Immer) وحالة الخطوط
  ui/         الواجهة: الشريط العلوي، الأدوات، اللوحة، المفتّش، الحوارات
tests/        اختبارات المحرّك والاستيراد والتحقّق (Vitest)
server.mjs    خادم ثابت لنسخة الإنتاج برؤوس أمان
```
